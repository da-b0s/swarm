**1. Gap-fill start (useEventLog.ts)**
`fetchIndexedHeight` is a new async function that fetches `{explorerBase}/api/v2/main-page/blocks`, parses the first item's `height`, and returns a `bigint`. It never throws — any failure returns `undefined`. It is called in parallel with `fetchAllExplorerLogs` via a single `Promise.all`, so it costs no extra round-trip time. After both resolve, `explorerCoveredTo = max(explorerHighBlock, indexedHeight)` and `rpcStart = explorerCoveredTo + 1n`. On a quiet contract this means the gap-fill starts from the explorer's current tip (e.g. block 28,813,134) rather than the last event block (potentially hundreds of thousands of blocks earlier), so the RPC phase is at most a few blocks. If the height fetch fails, `explorerHighBlock` is used as before.
